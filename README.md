# Бот регистрации на турнир MK1

Телеграм-бот для регистрации участников (Имя + Никнейм), рассылки правил
и автоматического напоминания за сутки с подтверждением участия.

## Установка

1. Установите Python 3.10+.
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Получите токен бота у [@BotFather](https://t.me/BotFather) (`/newbot`).
4. Скопируйте `.env.example` в `.env` и заполните:
   - `BOT_TOKEN` — токен от BotFather
   - `ADMIN_IDS` — ваш Telegram ID и ID других организаторов (узнать свой ID — у [@userinfobot](https://t.me/userinfobot))
   - `TOURNAMENT_DATETIME` — дата и время турнира
   - остальные параметры по желанию
5. Отредактируйте `rules.txt` — это текст, который бот отправляет по команде `/rules`.

## Запуск

### На Windows
- **Прямой запуск (терминал):** `python bot.py`
- **Запуск в фоне:** Дважды кликните `start_bot.vbs`
- **Остановка фонового процесса:** Запустите `stop_bot.bat`

### На macOS / Linux
- **Прямой запуск (терминал):** `python3 bot.py`
- **Запуск в фоне:** `./start_bot.sh`
- **Остановка фонового процесса:** `./stop_bot.sh`

> 💡 Подробный кросс-платформенный гайд по настройке рабочей среды на Windows и macOS см. в файле [CROSS_PLATFORM_GUIDE.md](file:///d:/AG/Telegram_Bot_MK/CROSS_PLATFORM_GUIDE.md).

Бот работает через polling — процесс должен быть запущен постоянно (на
сервере, VPS или локально).


## Как это работает

- Участник пишет `/start`, бот запрашивает Имя и Никнейм и сохраняет их в
  `participants.db` (SQLite, создаётся автоматически).
- `/rules` — правила, время и место (подтягивается из `rules.txt` и `.env`).
- `/mystatus` — участник видит свой статус регистрации/подтверждения.
- За `REMINDER_HOURS_BEFORE` часов (по умолчанию 24) до `TOURNAMENT_DATETIME`
  бот сам разошлёт всем зарегистрированным сообщение с кнопками
  «Подтверждаю» / «Не смогу».
- Ещё через `CONFIRMATION_CHECK_HOURS_AFTER` часов (по умолчанию 12) бот
  пришлёт админам список тех, кто не подтвердился.

## Админ-команды (только для ID из `ADMIN_IDS`)

- `/participants` — список всех зарегистрированных со статусом
- `/unconfirmed` — кто ещё не подтвердил участие
- `/broadcast текст` — разослать сообщение всем участникам

## Как обнулить регистрации (для тестирования)

Два способа:

1. **Через бота (проще всего):** отправьте админской командой
   ```
   /reset confirm
   ```
   Это удалит всех зарегистрированных участников, бот продолжит работать.

2. **Вручную:** остановите бота и удалите файл `participants.db` — он
   создастся заново при следующем запуске. Подходит, если хотите начать
   совсем с чистого листа (например, после теста перед реальным турниром).

Тестировать регистрацию удобно так: заполните `.env` тестовыми данными
(например, `TOURNAMENT_DATETIME` на ближайшее время, чтобы быстро увидеть
напоминание), пройдите регистрацию сами, проверьте `/rules`, `/mystatus`,
кнопки подтверждения — а затем `/reset confirm` и впишите реальную дату
турнира.

## Важно про напоминания

Задачи планируются **один раз при старте бота** относительно
`TOURNAMENT_DATETIME` из `.env`. Если бот перезапускается — задачи
переставляются заново (это нормально, `python-telegram-bot` считает время
от текущего момента). Если время турнира уже прошло к моменту запуска,
напоминание отправлено не будет — проверяйте `TOURNAMENT_DATETIME` перед
стартом.

## Файлы

- `bot.py` — основная логика бота
- `database.py` — работа с SQLite
- `config.py` — загрузка настроек из `.env` и `rules.txt`
- `rules.txt` — текст правил турнира (редактируется свободно)
- `.env.example` — шаблон настроек, скопировать в `.env`
- `requirements.txt` — зависимости
